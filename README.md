# TG_Bot_for_USPTU

Telegram-бот для автоматической проверки оформления курсовых, дипломных и других текстовых работ на соответствие требованиям **УГНТУ / ГОСТ**. Пользователь присылает боту `.docx`-файл, бот прогоняет его через макрос Microsoft Word, который находит нарушения оформления, подсвечивает их и оставляет комментарии прямо в документе, после чего возвращает готовый файл обратно.

## Как это работает

1. Пользователь отправляет боту `.docx`-документ.
2. Бот сохраняет файл во временную папку и просит подтвердить запуск проверки (кнопки «Да» / «Нет»).
3. После подтверждения Python через `pywin32` запускает скрытый экземпляр Microsoft Word и открывает документ.
4. В документе выполняется VBA-макрос `USPTU_Check.USPTU`, который последовательно проверяет оформление (см. раздел «Что проверяет макрос»).
5. Обработанный файл с подсветкой ошибок и комментариями сохраняется и отправляется пользователю обратно в чат.
6. Временные файлы (исходный и обработанный) удаляются после отправки.

```
Telegram (docx) → бот (main.py) → win32com → MS Word → макрос USPTU_Check.bas → docx с комментариями → Telegram
```

## Что проверяет макрос

Макрос анализирует основную часть документа (с 3-й страницы до конца — то есть без титульного листа и содержания) и отмечает:

- **Пробелы и переносы** — двойные пробелы, лишние пустые строки, некорректные пробелы перед знаками препинания.
- **Дефисы и тире** — путаницу между дефисом и тире, некорректные пробелы вокруг них.
- **Заголовки** («Введение», «Заключение», «Содержание», «Реферат», списки источников) — регистр букв, отсутствие знаков препинания в конце, выравнивание по центру, разрывы страниц до и после заголовка.
- **Списки** — корректность маркеров по уровням вложенности (тире / буква со скобкой / цифра со скобкой), абзацные отступы, знаки препинания в конце пунктов, заглавную букву в начале.
- **Шрифт и абзацы** — Times New Roman, кегль 14 (или 10/12/14 в таблицах), полуторный межстрочный интервал, отступы и выравнивание по ширине.
- **Курсив** — курсивное начертание запрещено, все такие фрагменты подсвечиваются.
- **Рисунки и таблицы** — пустые строки до/после, выравнивание, формат подписи («Рисунок 1.1 — Название», «Таблица 1 — Название»).
- **Параметры страницы** — поля документа (2 / 2 / 2 / 1 см) и наличие сквозной нумерации страниц.

Все найденные нарушения либо подсвечиваются красным (`wdRed`), либо сопровождаются комментарием Word с пояснением, что и как нужно исправить.

## Технологии

- **Python 3**, [`pyTelegramBotAPI`](https://github.com/eternnoir/pyTelegramBotAPI) (`telebot`) — логика Telegram-бота.
- **pywin32** (`win32com.client`, `pythoncom`) — управление Microsoft Word через COM.
- **python-dotenv** — хранение токена бота в `.env`.
- **VBA (Word Macro)** — сам алгоритм проверки оформления документа.

## Требования

- Windows с установленным **Microsoft Word** (бот управляет Word через COM-интерфейс, поэтому на Linux/macOS не запустится).
- Python 3.9+.
- Токен Telegram-бота, полученный у [@BotFather](https://t.me/BotFather).

## Установка

```bash
git clone https://github.com/ArtyomB-collab/TG_Bot_for_USPTU.git
cd TG_Bot_for_USPTU
pip install pytelegrambotapi pywin32 python-dotenv
```

Создайте файл `.env` в корне проекта:

```
BOT_TOKEN=ваш_токен_бота
```

### Подключение макроса

Код макроса из `USPTU_BOT_Check.bas` нужно один раз импортировать в модуль **`USPTU_Check`** глобального шаблона Word (`Normal.dotm`) или надстройки, доступной боту:

1. Открыть Word → `Alt+F11` (редактор VBA).
2. В `Normal` (или отдельном шаблоне-надстройке) создать модуль с именем `USPTU_Check`.
3. Вставить в него содержимое `USPTU_BOT_Check.bas`.
4. Сохранить и разрешить выполнение макросов в настройках безопасности Word.

После этого `word.Application.Run("USPTU_Check.USPTU")` из `main.py` сможет найти и выполнить макрос.

## Запуск

```bash
python main.py
```

Бот запускается в режиме long polling и готов принимать документы.

|---|---|
| `/start` | Приветствие и краткая инструкция |
| `/help` | Справка по возможностям и ограничениям |
| `/status` | Проверка, что бот запущен и работает |

## Ограничения

- Принимаются только файлы `.docx`.
- Максимальный размер файла — 20 МБ.
- Обработка одного документа занимает 1–5 минут в зависимости от объёма.
- Бот работает только на машине с установленным Microsoft Word (используется автоматизация через COM), то есть для продакшена нужен Windows-сервер или ПК с Word.

## Структура проекта

```
TG_Bot_for_USPTU/
├── main.py                 # логика Telegram-бота и запуск Word через COM
├── USPTU_BOT_Check.bas     # VBA-макрос с проверками оформления по ГОСТу
└── temp_files/             # временное хранилище загруженных и обработанных файлов
```
